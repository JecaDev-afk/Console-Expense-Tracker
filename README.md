# Console Expense Tracker

A lightweight, dependency-free command-line application for tracking personal finances and calculating balances with real-time currency conversion. 

## Features
* **Transaction Management:** Add income and expense records dynamically.
* **Persistent Storage:** Automatically saves and loads transaction history using local JSON files.
* **Live Currency Conversion:** Fetches real-time USD exchange rates from the National Bank of Ukraine (NBU) API to display the current balance in dollars.
* **Interactive CLI:** Menu-driven interface with input validation and error handling for robust user experience.

## Prerequisites
* Python 3.x
* `requests` library
